# Manual de usuario

La fuente editable es [`Manual Oficial - miClub Gestión.md`](<Manual Oficial - miClub Gestión.md>).
Las versiones [HTML](<Manual Oficial - miClub Gestión.html>) y
[PDF](<Manual Oficial - miClub Gestión.pdf>) se regeneran desde esa fuente.

Antes de distribuir el manual, comprobar que su fecha, capturas, rutas y flujo
operativo coincidan con el estado actual de la aplicación. El manual orienta al
usuario; no sustituye los documentos técnicos ni certifica un despliegue.
